# Правила проекта Sumi

Sumi — вайбкод VST3/AU-плагин для macOS, C++ / JUCE 8: рисует картинку на спектрограмме. Брат Mist, Eido и Talk2Me: те же темы, шрифты и страница About.
Репозиторий публичный: https://github.com/controloptioncommand/Sumi-vst

Перед любой работой с интерфейсом прочитай **[docs/DESIGN.md](docs/DESIGN.md)** — это обязательная дизайн-система.

## Общение
- Отвечать по-русски, коротко и по делу. Не начинать ответ с похвалы.
- Менять мнение только на аргументах, а не потому что пользователь не согласен.
- Если просьба неоднозначна (особенно по дизайну) — уточнить, а не придумывать от себя.

## Версии и патчноуты
- Текущая версия — в файле `VERSION` (схема: v1, v1.01 … v2, v2.01 …). На странице About она же в `Source/UI/About.h` (`AboutInfo::version`, `AboutInfo::date`).
- **У каждой версии обязателен патчноут** `docs/releases/<версия>.md` — без него CI не соберёт релиз.
- Новая версия: поменять `VERSION` и `AboutInfo` → добавить патчноут → коммит в `main`. CI сам соберёт, проверит (pluginval, auval, тест) и опубликует релиз с архивом `Sumi-macOS.zip`.
- Пока `VERSION` не меняется, новые сборки перезаписывают текущий релиз. Ветки `claude/**` только собираются (архив — в Artifacts сборки), релиз не публикуют.
- Ссылка на последнюю сборку: https://github.com/controloptioncommand/Sumi-vst/releases/latest/download/Sumi-macOS.zip
- После публикации дать пользователю эту ссылку и команду установки:
  ```bash
  cd ~/Downloads && rm -rf Sumi-macOS Sumi-macOS.zip && gh release download -R controloptioncommand/Sumi-vst -p Sumi-macOS.zip && unzip -q Sumi-macOS.zip -d Sumi-macOS && bash Sumi-macOS/install-mac.sh
  ```

## Сборка и проверка
```bash
cmake -B build -DSUMI_BUILD_TESTS=ON && cmake --build build --target SumiTest
./build/SumiTest_artefacts/Release/SumiTest ./render   # на Linux — через xvfb-run -a
```
Тест: таблица сумм картинки, частотные шкалы, прозрачность STFT (Imprint с белой картинкой = вход с задержкой, все размеры FFT), линия на заданной частоте во всех шкалах, **корреляция спектрограммы выхода с картинкой** (Paint, Add, Mask), привязка к тактам и задержке, Loop, остановленный транспорт, свободный ход, Mask вырезает / Add добавляет / Mix, крайние значения, состояние с картинкой, все пресеты, скорость, демо-WAV и спектрограммы, скриншоты в обеих темах, About. Перед коммитом тест должен печатать `ALL OK`. После изменений интерфейса — посмотреть скриншоты.

## Что нельзя ломать
- STFT: периодический Hann на анализ и синтез, перекрытие 75%, нормировка 1/1.5. Задержка плагина = размер FFT; картинка ставится на шкалу с учётом этой задержки (`SpectralEngine::doFrame`: центр кадра — момент `t − N/2`). Тест pass-through и timing это проверяет.
- Калибровка Paint: вся полоса белая → около −14 dBFS RMS при Level 0 dB (не зависит от ширины полосы и размера FFT).
- Картинка собирается в потоке сообщений (`SumiProcessor::rebuildPicture`) и передаётся в аудиопоток готовой; в аудиопотоке нет выделений памяти (буферы движка — под FFT 8192 заранее). Старые картинки держит `keepAlive`.
- Картинка хранится в состоянии проекта: встроенная и текст — только id/строка, своя — PNG (base64), не больше 1024×768.
- Выход защищён мягким лимитером (не выше 0 dBFS).
- Изменение диапазонов параметров ломает старые проекты и пресеты — предупреждать.

## Структура
- `Source/Picture.*` — картинка (яркость + таблица сумм), `Look` (яркость → громкость), встроенные картинки, текст, PNG в состоянии
- `Source/DSP/FreqMap.h` — шкалы Lin / Log / Mel; `Source/DSP/SpectralEngine.*` — STFT, Paint, Imprint (Add, Mask, Flatten)
- `Source/PluginProcessor`, `Params`, `Presets` — параметры, транспорт DAW, состояние, пресеты
- `Source/UI/` — `LookAndFeel` и `Widgets` (общие с Mist, Eido и Talk2Me), `Views` (Canvas / Live), `About`
- `Tests/SumiTest.cpp` — офлайн-тест; `scripts/` — установка и проверка приватности; `docs/` — руководство (`Sumi-manual.pdf`, исходник в `docs/manual/`), дизайн, картинки README, патчноуты
- При изменении ручек и поведения — обновлять руководство (`docs/manual/Sumi-manual.html` → `bash docs/manual/build.sh`) и README (пасхалки там не упоминать).
